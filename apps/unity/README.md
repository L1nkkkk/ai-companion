## Restore resources in a fresh checkout

Prerequisites: 64-bit Python 3.12.10 (repository baseline), PowerShell 7, official Unity 6000.3.11f1 with a working license and Windows Standalone x64 Mono support. Run from the repository root:

```powershell
python tools/unity/restore_assets.py --accept-live2d-terms
python tools/unity/verify_native_assets.py --output .bootstrap/unity/native-result.json
```

Read the resource conditions before the acceptance flag. Downloads are exclusively from fixed official URLs and verified before use. The SDK is restored under `Assets/Live2D`, preserving its upstream GUIDs and `.meta` files. The font and OFL notice are restored under `Assets/ThirdParty/Fonts` with stable GUIDs. Both acquired directories are ignored; no developer-specific path appears in scene references. `--cache <directory>` and `--sdk-package <official.unitypackage>` allow reuse of already verified downloads.

The two upstream root response files (`Assets/csc.rsp`, `Assets/mcs.rsp`) are intentionally omitted: the SDK's own assembly already enables unsafe code. All other assets/meta are restored. Do not edit acquired SDK assets; keep any future patch explicit and reviewable in tooling.

## Prepare, build and run (pending execution with Unity 6)

The checked-in scene is an authored candidate with fixed GUID references, not an Editor-validated scene. Initial preparation must run before building:

```powershell
pwsh -File tools/unity/Build-Windows.ps1 -UnityEditor '<official-editor>/Editor/Unity.exe' -PrepareOnly
```

`Prepare` configures URP with the official `CubismURPRenderer` as its default renderer, HDR off, Gamma color, Input System, D3D11, a windowed 1280×800 Player and Mono x64. It regenerates the foundation scene and standard Unity settings. Review generated `ProjectSettings`, `Packages/packages-lock.json`, `Assets/Companion/Settings`, the scene and all `.meta` files. Commit them after validation, then build without regenerating the scene:

```powershell
pwsh -File tools/unity/Build-Windows.ps1 -UnityEditor '<official-editor>/Editor/Unity.exe'
pwsh -File tools/unity/Test-Player.ps1 -Player '<build-folder>/AICompanion.Foundation.exe' -EvidenceDirectory '<new-evidence-folder>' -Seconds 600
```

The build script rejects missing or different Editor versions. It creates a new Windows folder, ZIP, build log and SHA-256 receipt only after Unity returns its explicit success marker. A dirty-source receipt is not accepted as exact-commit evidence. Raw Unity logs may contain machine/licensing identifiers; inspect and redact before publishing.

The Player probe is a real graphical launch, not headless rendering. The candidate fixture instantiates the official Mao prefab, adds the SDK motion controller for a single sample idle clip, fits its camera, and displays a read-only Chinese scope label using the pinned font. It does not call a backend or activate a microphone. Esc closes the application. Captures at 3 and 10 seconds and a bounded frame-time CSV are produced only when an evidence directory is requested. Inspect the captures for missing/pink materials, normal and inverted masks and draw order. Counters and clean logs alone do not prove correct appearance. The supplied runtime and editor C# have not yet compiled in Unity 6.
