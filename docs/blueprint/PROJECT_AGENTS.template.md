本文件由 A0 在正式代码仓库建立后复制为根目录 AGENTS.md。它不是当前 ChatGPT 同步目录的指令替换文件。

当前有效技术方向为 Unity / C# + Cubism SDK for Unity，先交付 Windows 原型，见 [ADR15](../adr/0015-unity-client-and-design-only-a0.md) 和 [U01](../tasks/U01/TASKBOOK.md)。A0 设计会话只编写设计、派工文档、评审和验收已有产物；不创建工程、实现、修复或打包。实际编码与集成由独立开发会话承担，未被用户要求时不自动创建开发任务。复制模板时必须保留此规则，并参考根 AGENTS 的完整边界。

## 项目目标

实现桌面语音聊天、一个真实直播平台的弹幕互动，以及 Android 和 iOS 独立 App。手机支持用户主动开启的后台陪伴语音；灵动岛、锁屏实时活动和 Android 持续通知负责状态和快捷操作。AI 初期使用云端服务。

## 分工与工作范围

开发 owner 按任务 ID 在独立分支或 worktree 开发，只修改分配目录，自主完成范围内实现、修复与测试。A0 负责接口、状态机、目录边界和集成方案评审；指定开发 owner 实施集成。派工以用户启动的开发会话为准。

## 必须保持的行为

- 后台音频、连接和凭据续期归手机原生引擎；不能依靠暂停中的 Unity 主循环、WebView 或 JS 定时器。
- 停止操作先本机静音，然后取消服务端；旧 turn 和 epoch 的音频、字幕与动作丢弃。
- 每个 session 只有一个输入设备和一个播放设备；接管必须显式。
- 个人和直播上下文及记忆隔离；显示端不能获得控制者权限。
- 云端密钥由服务端保管；麦克风静音后停止上传，结束后停止录音。
- 原始录音不默认持久化；历史与记忆支持删除。
- 不把 mock、模拟器或静态截图当作真实手机后台或直播接入验证。
- 不使用伪造通话、循环静音音频或绕过平台权限的方法掩盖能力缺口。
