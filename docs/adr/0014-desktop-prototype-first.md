# ADR14：先交付本机桌面原型

日期：2026-09-20。决策人：A0。状态：接受。用户明确要求先在当前电脑上体验，Mac 暂不可参与，并确认先用演示角色。

## 决策与边界

新增独立交付 P01，先提供 React 桌面聊天工作台、可替换的原创 SVG 角色、文字流式回应、系统语音播放、实际音量口型、显式打断及浏览器内历史。无需等待 Mac、手机签名、直播权限或模型素材。产品暂名“伴星 HOSHI”，未作商标或公开发布决定。

默认 demo 使用明确标注的预设回应。保留由本机后台配置的 Chat Completions 云端适配器；没有密钥时不调用外部模型，也不把预设回答说成真实 AI。角色界面明确标注“非 Live2D”。没有导入 Cubism Core 或第三方模型。

本交付使用 `/prototype/*` 临时接口，仅由绑定 `127.0.0.1` 的开发服务暴露，并限制 Host 和浏览器 Origin。它不提供账号、设备租约或会话接管，不适合部署到公网。冻结的 `/v1/*`、WSS、音频头及其契约清单没有改变。由 A0 登记根依赖、锁文件、CI、前端与 API 的共同修改。

Windows 使用系统语音在内存中生成 WAV；浏览器播放并根据实际 PCM 波形驱动口型。其他系统回退到浏览器 SpeechSynthesis，无法取得其音频波形时不驱动嘴型。语音输入是用户主动点击的单次浏览器识别，文字写入输入框，由用户确认发送。识别可由浏览器在线服务完成；未证明离线识别、连续收音或手机后台能力。

## 与 R1 的关系

P01 独立记录于 [原型台账](../blueprint/planning/prototype.json)，不更改原 21 个任务的验收状态，不提前宣布 G0/G1 或 R1 完成。T00 的第二台机器、原生依赖锁和资源登记仍待验证；T01/T02/T03 的真实设备及直播验证保留。

当前一次性系统 WAV 与浏览器 ASR 不是冻结的实时音频协议实现。临时端点不能作为手机或直播 agent 的正式依赖；新增消费者须使用 contracts 的正式定义。

## 验证与回退

执行原有全仓检查和新桌面交互测试。重点验证原型诚实状态、实际语音、打断、切换会话、刷新保存、删除、故障提示和窄窗口布局。真实云端、真实麦克风识别、Mac、Live2D 和手机后台列为未验证。

实现独立位于 `app/prototype`、网页 UI 与启动器。关闭 router 或回退 P01 即恢复基础服务，冻结契约无需迁移。云端接入只通过用户配置 `.env` 显式开启；不新增默认付费调用。
