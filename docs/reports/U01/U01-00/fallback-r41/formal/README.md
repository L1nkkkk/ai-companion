# Formal evidence copies

Source commit: 849c6c982d875f477d88933af4abea5a163d0fa6.

All PNGs are unchanged actual Player output. JSON/text copies are normalized to UTF-8 LF. `evidence-hashes.json` is the original runtime inventory and describes raw local files, including the unpublished raw player.log; its hashes do not describe the normalized copies. `published-copy-hashes.json` describes the files in this evidence ZIP, excluding itself. The ZIP contains every first-cycle screenshot, while Git stores a selected subset. Original Editor/Player logs remain local and their hashes are in verification-summary.json; filtered diagnostic excerpts are clearly labelled.

This validates a foundation rendering fixture. It is not final A0 acceptance, a production AvatarPresenter, real audio lip sync, or a completed companion application. See verification-summary.json and visual-review.json for measurement and appearance limitations.
